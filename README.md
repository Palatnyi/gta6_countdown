# gta6_countdown

Кількість унікальних користувачів, які написали боту в приватному чаті, виводиться в консоль під час запуску та при появі нового користувача. Історія зберігається локально у `data/users.json` і не потрапляє до Git. Лічильник охоплює користувачів, які взаємодіяли з ботом після додавання цієї функції, а не всіх підписників Telegram.

Для сповіщень про кожного нового користувача задайте у `.env`:

```env
ADMIN_BOT_TOKEN=токен_окремого_бота_для_сповіщень
ADMIN_CHAT_ID=ваш_telegram_chat_id
```

Спершу відкрийте окремий бот і надішліть йому `/start`, інакше Telegram не дозволить йому написати вам. Сповіщення містить username (або Telegram ID, якщо username відсутній), дату й час за Києвом та номер користувача за порядком.
